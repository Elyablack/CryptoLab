# CryptoLab: правила разработки

CryptoLab — исследовательская платформа для анализа криптовалютного рынка.

1. Проект предназначен для анализа криптовалютного рынка, а не для
   автоматической торговли.
2. Запрещено реализовывать отправку реальных торговых ордеров.
3. Не использовать приватные API-ключи без отдельного согласования.
4. Предпочитать простые решения без преждевременного усложнения архитектуры.
5. Каждый новый компонент должен сопровождаться тестами.
6. Unit-тесты должны выполняться без доступа к интернету.
7. Перед значительными изменениями сначала показывать план.
8. Не выполнять `git commit` и `git push` без явного разрешения.
9. Не изменять несвязанные файлы.
10. После реализации объяснять ключевые решения и показывать результаты
    тестирования.
