# CryptoLab

CryptoLab — исследовательская платформа для изучения и анализа
криптовалютного рынка.

Первый компонент проекта — Market Data Collector. Он будет получать
исторические часовые OHLCV-данные для спотовых пар `BTC/USDT` и `ETH/USDT` из
публичного Binance Spot API, проверять полноту и корректность данных и сохранять
их в SQLite.

Основные принципы проекта:

- простая и проверяемая архитектура;
- воспроизводимый и идемпотентный сбор данных;
- явный контроль качества и пропусков;
- отсутствие приватных API-ключей и торговых операций;
- постепенная реализация небольшими тестируемыми итерациями.
